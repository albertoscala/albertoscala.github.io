5. Projects

   vulkan_runtime.h
      Vulkan-based runtime enabling CUDA-style GPU programming
      across platforms with a familiar CUDA runtime-like API.
      https://github.com/albertoscala/vulkan_runtime.h

   open-mps
      Open-source reimplementation of NVIDIA Multi-Process
      Service (MPS) for legacy and unsupported GPUs, enabling
      multi-process GPU sharing and scheduling experimentation.
      https://github.com/albertoscala/open-mps

   cuda-types
      Host-side implementations of CUDA built-in types for
      use outside of nvcc environments.
      https://github.com/albertoscala/cuda-types

      Arena-style GPU memory allocator for CUDA conforming to

      deterministic device memory allocation.
      https://github.com/albertoscala/cuda-bump-allocator
